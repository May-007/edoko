# edoko
Projet étudiant indépendant visant à enrichir l'environnement numérique de travail de l'Université de Technologie de Compiègne (UTC). Via une extension de navigateur dédiée, ce projet intègre de nouveaux outils applicatifs et fonctionnels afin de centraliser et de fluidifier le suivi académique quotidien des étudiants.
